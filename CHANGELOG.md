# Changelog

## 0.3.0 — 2026-10-23

- Add configurable keybind controls with input capture, cancellation, and an
  option to clear the binding.
- Match native Gamepad heading styles, row spacing, and label typography.
- Separate mod sections with larger heading gaps.
- Size the shared label column to fit setting names while keeping controls
  inside the panel.
- Preserve native button and dropdown sizes and keep slider values beside their
  tracks.
- Update the package icon and release tooling.

## 0.2.0 — 2026-10-19

- Add integer sliders and refresh both settings menus when preferences change.
- Validate setting names, counts, and slider ranges.

## 0.1.1 — 2026-09-20

- Display enum dropdown options as readable words.

## 0.1.0 — 2026-09-20

- Add a shared Mods tab to the main-menu and pause-menu settings.
- Support MelonPreferences toggles, sliders, and enum dropdowns.
- Include the release DLL in the repository.
